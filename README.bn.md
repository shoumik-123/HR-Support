## ১. এই প্রজেক্টটা আসলে কী?

**Veyra Talent** একটি **রিক্রুটমেন্ট সফটওয়্যার** (চাকরির নিয়োগ ব্যবস্থাপনা সিস্টেম)।
একটা কোম্পানির HR টিম যে কাজগুলো করে — চাকরির বিজ্ঞপ্তি দেওয়া, CV জমা নেওয়া,
প্রার্থী বাছাই করা, ইন্টারভিউ নেওয়া, ইমেইল পাঠানো — সেই পুরো প্রক্রিয়াটা এই
সফটওয়্যারে হয়।

এর বিশেষত্ব হলো **AI দিয়ে CV পড়া ও প্রার্থী মিলিয়ে দেখা**। হাজারটা CV হাতে পড়ার
বদলে সফটওয়্যারটি নিজে পড়ে, তথ্য বের করে, আর চাকরির সাথে কে কতটা মেলে তার একটা
স্কোর দেয় — **প্রমাণসহ**, অর্থাৎ CV-র ঠিক কোন লাইন দেখে সে এই কথা বলছে তা দেখায়।

### গুরুত্বপূর্ণ কথা: AI সিদ্ধান্ত নেয় না

এই সফটওয়্যারে AI কখনো নিজে থেকে কাউকে বাতিল করে না, নিয়োগ দেয় না, বা স্টেজ
পরিবর্তন করে না। AI শুধু **পরামর্শ** দেয় — চূড়ান্ত সিদ্ধান্ত সবসময় মানুষের।
প্রতিটি মানবিক সিদ্ধান্ত কে নিয়েছে, কখন নিয়েছে, কী কারণে নিয়েছে — সব লগে থাকে।

### প্রজেক্টের দুটি অংশ

| অংশ | কী কাজ করে | ফোল্ডার |
|---|---|---|
| **API (ব্যাকএন্ড)** | সব ডেটা, লজিক, AI, ডেটাবেস | `apps/api` |
| **Web (ফ্রন্টএন্ড)** | যে স্ক্রিনগুলো আপনি ব্রাউজারে দেখেন | `apps/web` |

দুটোই একসাথে চালু থাকতে হবে, নাহলে কাজ করবে না।

## ২. কীভাবে চালু করবেন

### প্রথমবার (একবারই করতে হবে)

টার্মিনাল খুলুন, প্রজেক্ট ফোল্ডারে যান, তারপর:

```bash
cd c:/Users/user/Downloads/Project/HR_Support
pnpm install
```

এতে সব প্রয়োজনীয় প্যাকেজ ডাউনলোড হবে (কয়েক মিনিট লাগতে পারে)।

### প্রতিবার চালু করার নিয়ম

**তিনটি আলাদা টার্মিনাল** লাগবে। তিনটিই খোলা রাখতে হবে — একটা বন্ধ করলে সেই অংশ
কাজ করা বন্ধ করে দেবে।

#### টার্মিনাল ১ — ডেটাবেস

```bash
cd c:/Users/user/Downloads/Project/HR_Support
pnpm db:start
```

অপেক্ষা করুন যতক্ষণ না দেখায়:
```

```

#### টার্মিনাল ২ — API (ব্যাকএন্ড)

```bash
cd c:/Users/user/Downloads/Project/HR_Support/apps/api
pnpm dev
```

অপেক্ষা করুন যতক্ষণ না দেখায়:
```

```

#### টার্মিনাল ৩ — Web (ফ্রন্টএন্ড)


### ডেমো ডেটা ঢোকানো (প্রথমবার, বা নতুন করে শুরু করতে চাইলে)

API বন্ধ না করে, **চতুর্থ একটি টার্মিনালে**:

```bash
cd c:/Users/user/Downloads/Project/HR_Support/apps/api

```

এতে ডেমো কোম্পানি, ৫ জন ব্যবহারকারী, ৬ জন প্রার্থী, ৩টি চাকরি, ২টি ইন্টারভিউ
আর ১০টি ইমেইল টেমপ্লেট তৈরি হবে।

> ⚠️ **সাবধান:** `pnpm db:seed` চালালে আগের ডেমো ডেটা **মুছে গিয়ে** নতুন করে তৈরি

## ৫. ফিচার সমূহ — কীভাবে ব্যবহার করবেন

### ৫.১ ড্যাশবোর্ড (Dashboard)

লগইন করলেই এই পেজ আসে। এখানে এক নজরে দেখবেন:

- **Active jobs** — কতগুলো চাকরি চালু আছে
- **Candidates** — মোট কতজন প্রার্থী
- **Applications** — কতগুলো আবেদন, কতজন নিয়োগ পেয়েছে
- **Awaiting AI review** — AI কতগুলো সুপারিশ দিয়েছে যা এখনো কেউ দেখেনি
- **Recruitment funnel** — কোন স্টেজে কতজন আটকে আছে (বার চার্ট)
- **AI oversight** — AI-এর সুপারিশ মানুষ কতটা মানছে, কতটা বদলাচ্ছে

উপরের ডানে **Last 30 days** ড্রপডাউন দিয়ে সময়সীমা বদলাতে পারবেন।

### ৫.২ চাকরি তৈরি করা (Jobs)

**ধাপ:**

1. বাম মেনু থেকে **Jobs** → উপরে ডানে **New job** বাটন
2. চাকরির নাম লিখুন (যেমন: `Senior Full Stack Engineer`)
3. **✨ Draft with AI** বাটনে চাপ দিলে AI পুরো বিবরণ লিখে দেবে
   *(শুধু চাকরির নাম দিলেই হবে)*
4. **Required skills** — যে দক্ষতাগুলো অবশ্যই লাগবে
   *(টাইপ করে Enter চাপুন, একটার পর একটা যোগ হবে)*
5. **Preferred skills** — থাকলে ভালো, না থাকলেও চলবে
6. অভিজ্ঞতা, শিক্ষাগত যোগ্যতা, বেতন ইত্যাদি পূরণ করুন
7. **Matching weights** — AI কোন বিষয়ে কত গুরুত্ব দেবে
   *(মোট ১০০% হতে হবে, নাহলে সেভ হবে না)*
8. **Save as draft** (খসড়া) অথবা **Save and publish** (প্রকাশ)

**Matching weights মানে কী?**
ধরুন আপনি Skills-এ ৬০% দিলেন আর Education-এ ৫%। তাহলে AI স্কোর দেওয়ার সময়
দক্ষতাকে অনেক বেশি গুরুত্ব দেবে, সার্টিফিকেটকে কম। প্রতিটি চাকরির জন্য আলাদা
করে ঠিক করতে পারবেন।

---

### ৫.৩ CV আপলোড করা (Upload resumes)

**ধাপ:**

1. বাম মেনু → **Upload resumes**
2. উপরে **"Add candidates to a job"** থেকে চাকরি বাছুন
   *(বাছলে প্রার্থীরা সরাসরি সেই চাকরির পাইপলাইনে ঢুকবে)*
3. CV ফাইলগুলো **টেনে এনে ছেড়ে দিন**, অথবা **Choose files** চাপুন
4. **Upload** বাটনে চাপুন

**কী কী ফাইল চলবে:**
- PDF, DOC, DOCX
- **ZIP ফাইল** — ভেতরে অনেকগুলো CV থাকলে সব একসাথে খুলে নেবে
- একবারে সর্বোচ্চ ১০০টি ফাইল, প্রতিটি ১০ MB পর্যন্ত

**আপলোডের পর কী হয়:**

ডান পাশে অগ্রগতি দেখবেন — **Parsed** (পড়া হয়ে গেছে), **In progress** (চলছে),
**Failed** (ব্যর্থ)। সফটওয়্যারটি পেছনে কাজ করে, তাই আপনি অন্য পেজে চলে গেলেও
কাজ চলতে থাকবে।

**নিরাপত্তা ব্যবস্থা (স্বয়ংক্রিয়):**
- ফাইলের ভেতরটা পরীক্ষা করে — `.pdf` নাম দিয়ে ভাইরাস পাঠালে ধরা পড়বে
- ম্যাক্রোযুক্ত Word ফাইল বাতিল হয়
- একই CV দুবার দিলে ধরে ফেলে, দুবার প্রার্থী তৈরি করে না
- ইমেইল বা ফোন নম্বর মিলে গেলে পুরনো প্রার্থীর সাথে জুড়ে দেয়

### ৫.৪ AI দিয়ে প্রার্থী বাছাই (সবচেয়ে গুরুত্বপূর্ণ ফিচার)

**ধাপ:**

1. **Jobs** → যে চাকরিটা চান সেটায় ক্লিক করুন
2. উপরে ডানে **✨ Screen candidates** বাটনে চাপুন
3. **Ranking** ট্যাবে চলে যাবে — কয়েক সেকেন্ড পর স্কোর আসবে

**যা দেখবেন:** প্রার্থীরা স্কোর অনুযায়ী সাজানো — সবচেয়ে মানানসই উপরে।

**"Why?" বাটনই আসল জিনিস।** চাপ দিলে দেখবেন:

- **প্রতিটি বিষয়ে আলাদা স্কোর** — Skills, Experience, Education, Projects, Certifications
- **কারণ** — কেন এই স্কোর দিল
- **প্রমাণ** — CV-র ঠিক কোন লাইন দেখে বলছে *(উদ্ধৃতি আকারে)*
- **Matched skills** — যে দক্ষতাগুলো পাওয়া গেছে
- **Missing required skills** — যেগুলো পাওয়া যায়নি
- **Confidence** — AI কতটা নিশ্চিত

**আপনি স্কোর বদলাতে পারবেন:**

- **Looks right** — AI ঠিক বলেছে
- **Adjust or dismiss** — স্লাইডার দিয়ে নিজের স্কোর দিন, বা সুপারিশ বাতিল করুন

আপনার দেওয়া স্কোরই চূড়ান্ত হবে, AI-এরটা নয়। ড্যাশবোর্ডে দেখা যাবে মানুষ গড়ে
কতটা বদলাচ্ছে — AI ভুল করলে তা ধরা পড়বে।

**গোপনীয়তা:** AI-এর কাছে পাঠানোর আগে প্রার্থীর **নাম, ইমেইল, ফোন** মুছে ফেলা হয়।
সেই সাথে **জন্মতারিখ, ধর্ম, বৈবাহিক অবস্থা, জাতীয়তা, পিতা-মাতার নাম** — এই
লাইনগুলোও বাদ দেওয়া হয়, কারণ এগুলো চাকরির সাথে সম্পর্কিত নয়। বাংলাদেশি CV-তে
এসব প্রায়ই থাকে, তাই এটা বিশেষভাবে জরুরি।

---

### ৫.৫ পাইপলাইন — প্রার্থী এগিয়ে নেওয়া (Pipeline)

**Jobs** → চাকরি → **Pipeline** ট্যাব

এখানে কানবান বোর্ড দেখবেন। ডিফল্ট স্টেজগুলো:

```
Applied → Screening → Shortlisted → Assessment → Interview
    → Final Review → Offer → Hired / Rejected
```

**কী করতে পারবেন:**

- **কার্ড টেনে অন্য কলামে ছাড়ুন** — প্রার্থী সেই স্টেজে চলে যাবে
- **Interview** লেখায় চাপ দিন — সরাসরি ইন্টারভিউ শিডিউল করতে পারবেন
- **Reject** লেখায় চাপ দিন — কারণ লিখতে হবে *(বাধ্যতামূলক)*

> প্রত্যাখ্যানের সময় কারণ লেখা **বাধ্যতামূলক**, এবং কে প্রত্যাখ্যান করল তা
> অডিট লগে থেকে যায়। AI কখনো নিজে কাউকে প্রত্যাখ্যান করতে পারে না।

স্টেজগুলো বদলাতে চাইলে: **Settings → Pipeline** (HR Manager বা Owner লাগবে)

---

### ৫.৬ প্রার্থীর সম্পূর্ণ প্রোফাইল (Candidate 360)

**Candidates** → যেকোনো নামে ক্লিক করুন

ছয়টি ট্যাব পাবেন:

| ট্যাব | কী আছে |
|---|---|
| **Profile** | অভিজ্ঞতা, শিক্ষা, প্রজেক্ট, সার্টিফিকেট, দক্ষতা |
| **Applications** | কোন কোন চাকরিতে আবেদন করেছে, স্কোর কত |
| **Interviews** | সব ইন্টারভিউ ও তার ফিডব্যাক |
| **Resumes** | সব CV ফাইল, ডাউনলোড করা যায় |
| **Notes** | টিমের নোট |
| **Activity** | এই প্রার্থীকে নিয়ে কে কী করেছে, সব |

**"Show source" বাটন:** Profile ট্যাবে প্রতিটি তথ্যের পাশে এই বাটন আছে। চাপ
দিলে CV-র ঠিক যে লাইন থেকে তথ্যটা নেওয়া হয়েছে তা দেখাবে। অর্থাৎ AI যা বলছে
আপনি নিজে যাচাই করতে পারবেন।

**Export data** বাটন দিয়ে প্রার্থীর সব তথ্য JSON ফাইলে নামানো যায়
(ডেটা সুরক্ষা আইনের জন্য দরকার হয়)।

---

### ৫.৭ ইন্টারভিউ (Interviews)

#### ক) সময়সূচি ঠিক করা

**পাইপলাইন কার্ডে "Interview"** চাপুন। যে উইন্ডো আসবে:

1. **Interview template** বাছুন *(ঐচ্ছিক — সময় ও মূল্যায়নের মানদণ্ড ঠিক করে দেয়)*
2. **Interviewers** — কারা ইন্টারভিউ নেবে *(প্রথম জন "lead" হবেন)*
3. **✨ Suggest free slots** চাপুন — সফটওয়্যার দেখবে কখন সবাই ফ্রি আছেন
4. একটা সময় বাছুন, বা নিজে তারিখ-সময় লিখুন
5. **Meeting link** দিন (Zoom/Meet-এর লিংক)
6. **"Email the candidate"** টিক দেওয়া থাকলে প্রার্থী ইমেইল + ক্যালেন্ডার
   ইনভাইট (.ics) পাবে
7. **Schedule interview** চাপুন

**সংঘর্ষ ধরা পড়লে:** কেউ ঐ সময়ে অন্য ইন্টারভিউতে থাকলে সতর্কবার্তা দেখাবে।
তবুও বুক করতে চাইলে **Book anyway** আছে।

**নিজের ফ্রি সময় জানানো:** প্রতিটি ইন্টারভিউয়ার নিজের সাপ্তাহিক সময় ঠিক করতে
পারেন, যাতে slot খোঁজা কাজ করে।

#### খ) প্রশ্ন তৈরি করা

ইন্টারভিউ পেজে **✨ Suggest questions** চাপুন:

- কয়টা প্রশ্ন চান, কী কঠিন মাত্রার — বেছে নিন
- **"Tailor questions to this candidate's resume"** টিক দিলে প্রার্থীর নিজের
  অভিজ্ঞতা ধরে প্রশ্ন তৈরি হবে
- প্রতিটি প্রশ্নের সাথে পাবেন:
  - **Listen for** — ভালো উত্তর কেমন হবে, দুর্বল উত্তর কেমন
  - **কেন এই প্রশ্ন** — CV-র কোন দাবি যাচাই করতে
- পছন্দের প্রশ্নে টিক দিয়ে **Add to this interview** চাপুন

> প্রশ্নে কখনো বয়স, ধর্ম, লিঙ্গ, বৈবাহিক অবস্থা নিয়ে কিছু আসবে না — এটা
> সফটওয়্যারেই আটকানো আছে।

#### গ) ফিডব্যাক দেওয়া (Scorecard)

ইন্টারভিউ শেষে ইন্টারভিউয়ার পেজে গিয়ে:

1. প্রতিটি মানদণ্ডে **১ থেকে ৫** রেটিং দিন
   *(১ = মান অনেক নিচে, ৩ = মান ঠিক আছে, ৫ = মানের অনেক উপরে)*
2. প্রতিটির পাশে প্রমাণ লিখতে পারেন
3. **Strengths** ও **Concerns** লিখুন
4. **✨ Tidy my notes** চাপলে AI আপনার নোটগুলো গুছিয়ে সারসংক্ষেপ বানাবে
5. **Your recommendation** বাছুন (Strong yes → Strong no)
6. **Submit feedback**

**গুরুত্বপূর্ণ নিয়ম:** আপনি নিজের ফিডব্যাক জমা না দেওয়া পর্যন্ত **অন্যদের রেটিং
দেখতে পাবেন না**। কারণ অন্যের মত দেখে ফেললে নিজের মত প্রভাবিত হয়ে যায়।

জমা দেওয়ার পর পুরো প্যানেলের ফিডব্যাক দেখবেন। প্যানেলে মতভেদ থাকলে সফটওয়্যার
সেটা **"split"** বলে দেখাবে — কিন্তু নিজে কোনো সিদ্ধান্ত দেবে না, আলোচনার জন্য
জানিয়ে দেবে মাত্র।

#### ঘ) ক্যালেন্ডার

বাম মেনু → **Interviews** — সপ্তাহভিত্তিক ক্যালেন্ডার। **"Only mine"** টিক দিলে
শুধু নিজের ইন্টারভিউ দেখবেন। ফিডব্যাক বাকি থাকলে উপরে সতর্কবার্তা আসবে।

---

### ৫.৮ ইমেইল ও যোগাযোগ (Communications)

তিনটি ট্যাব:

#### Sent messages (পাঠানো বার্তা)
সব ইমেইলের রেকর্ড — কাকে, কখন, সফল হয়েছে কি না। ব্যর্থ হলে **Try sending again**।

#### Templates (টেমপ্লেট)
১০টি তৈরি টেমপ্লেট আছে — আবেদন গ্রহণ, শর্টলিস্ট, ইন্টারভিউ আমন্ত্রণ, প্রত্যাখ্যান
ইত্যাদি। সম্পাদনা করতে **HR Manager** রোল লাগবে।

টেমপ্লেটে প্লেসহোল্ডার ব্যবহার করবেন:
```
প্রিয় {{candidate.firstName}},
{{job.title}} পদের জন্য আপনার আবেদন পেয়েছি।
```
পাঠানোর সময় এগুলো আসল নাম-পদবি দিয়ে পূরণ হয়ে যাবে। ভুল প্লেসহোল্ডার লিখলে
সেভ হবে না — আগেই ধরিয়ে দেবে।

#### Automations (স্বয়ংক্রিয় ইমেইল)
কখন আপনাআপনি ইমেইল যাবে তা ঠিক করুন — যেমন কেউ আবেদন করলে, বা শর্টলিস্ট হলে।

> **সব অটোমেশন শুরুতে বন্ধ থাকে।** আপনি নিজে চালু না করা পর্যন্ত প্রার্থীর কাছে
> কোনো স্বয়ংক্রিয় ইমেইল যাবে না। চালু করলে সেটাও অডিট লগে লেখা থাকে।

> ⚠️ **এখন ইমেইল আসলে পাঠানো হয় না।** SMTP সেট করা নেই, তাই ইমেইলগুলো
> **API টার্মিনালে লেখা হয়**। সেখানে তাকালে পুরো ইমেইল দেখতে পাবেন।
> আসল ইমেইল পাঠাতে `apps/api/.env` ফাইলে `SMTP_URL` বসাতে হবে।

---

### ৫.৯ পরীক্ষা (Assessments)

#### ক) প্রশ্ন ও প্রশ্নপত্র তৈরি

পরীক্ষার প্রশ্ন ৫ ধরনের হতে পারে:

| ধরন | কে নম্বর দেয় |
|---|---|
| এক উত্তর (MCQ single) | সফটওয়্যার নিজেই |
| একাধিক উত্তর (MCQ multi) | সফটওয়্যার নিজেই |
| সংখ্যা (Numeric) | সফটওয়্যার নিজেই (সহনীয় মাত্রাসহ) |
| সংক্ষিপ্ত উত্তর | মানুষ |
| রচনামূলক উত্তর | মানুষ |

> একাধিক উত্তরের প্রশ্নে **আংশিক নম্বর নেই** — সব সঠিক উত্তর দিলে পুরো নম্বর, নাহলে শূন্য।
> কারণ অর্ধেক সঠিক উত্তর থেকে প্রার্থীর দক্ষতা বোঝা যায় না।

#### খ) প্রার্থীকে পরীক্ষা পাঠানো

1. **Jobs** → চাকরি → **Pipeline** ট্যাব
2. প্রার্থীর কার্ডে **Assess** লেখায় চাপ দিন
3. প্রশ্নপত্র বাছুন, লিংক কত দিন কাজ করবে ঠিক করুন
4. **Send assessment** চাপুন

প্রার্থী একটি **ব্যক্তিগত লিংক** পায় — তার কোনো অ্যাকাউন্ট বা পাসওয়ার্ড লাগে না।
লিংকটি একজনের জন্যই কাজ করে।

#### গ) প্রার্থী যা দেখে

- পরীক্ষা শুরুর আগে: কত প্রশ্ন, কত সময়, কত নম্বর
- **Begin** চাপলে ঘড়ি চালু হয় — আর থামে না
- উত্তর **নিজে নিজে সেভ হয়** (ইন্টারনেট গেলে কাজ হারাবে না)
- সময় শেষ হলে **নিজে নিজে জমা** হয়ে যায়
- একবারই জমা দেওয়া যায়

> প্রার্থীর কাছে **সঠিক উত্তর কখনো পাঠানো হয় না** — শুধু প্রশ্ন আর অপশন।

#### ঘ) খাতা দেখা

**Assessments** মেনুতে যান। যে খাতায় রচনামূলক উত্তর আছে সেখানে **Mark** লেখা থাকবে।

- MCQ ও সংখ্যার প্রশ্ন **আগেই নম্বর পেয়ে গেছে**
- রচনামূলক উত্তরে আপনি নম্বর ও মন্তব্য দেবেন
- **সব উত্তর দেখা না হওয়া পর্যন্ত চূড়ান্ত শতকরা নম্বর প্রকাশ হয় না** — অর্ধেক দেখা
  খাতাকে কখনো চূড়ান্ত ফলাফল হিসেবে দেখানো হয় না

### ৫.১০ নিয়োগপত্র (Offers)

#### ক) নিয়োগপত্র তৈরি

1. **Pipeline** → প্রার্থীর কার্ডে **Offer** চাপুন
2. বেতন, যোগদানের তারিখ, উত্তর দেওয়ার শেষ তারিখ দিন
3. প্রবেশন, নোটিশ পিরিয়ড, কাজের স্থান লিখুন
4. **Benefits** যোগ করুন (উৎসব বোনাস, স্বাস্থ্য বীমা ইত্যাদি — এক ক্লিকে)
5. **কে কে অনুমোদন দেবে** বাছুন
6. **Create** চাপুন

চিঠিটি আপনার টেমপ্লেট থেকে স্বয়ংক্রিয়ভাবে তৈরি হয় — পাঠানোর আগে পড়ে দেখতে পারবেন।

#### খ) অনুমোদন প্রক্রিয়া

- যাদের বাছা হয়েছে **সবাই অনুমোদন না দিলে** নিয়োগপত্র পাঠানো যাবে না
- একজন প্রত্যাখ্যান করলে এটি আবার খসড়ায় ফিরে যায়
- **শর্ত বদলালে আগের সব অনুমোদন বাতিল হয়ে যায়** — কারণ তারা পুরনো শর্তে সম্মতি
  দিয়েছিলেন। এতে কম বেতনে অনুমোদন নিয়ে পরে বাড়িয়ে পাঠানো সম্ভব হয় না
- **Recruiter নিয়োগপত্র পাঠাতে পারে না** — শুধু HR Manager বা Owner পারে

#### গ) প্রার্থী যা দেখে

প্রার্থী একটি লিংক পায় যেখানে থাকে:

- পদ, বেতন, যোগদানের তারিখ, উত্তরের শেষ তারিখ
- সব সুযোগ-সুবিধার তালিকা
- সম্পূর্ণ নিয়োগপত্র
- **Accept** বা **Decline** বাটন (কারণ লিখতে পারে, বাধ্যতামূলক নয়)

**গ্রহণ করলে** প্রার্থী স্বয়ংক্রিয়ভাবে **Hired** স্টেজে চলে যায় এবং অনবোর্ডিং
চেকলিস্ট তৈরি হয়ে যায়।

### ৫.১১ অনবোর্ডিং (Onboarding)

**Offers** → **Onboarding** ট্যাব

প্রার্থী নিয়োগপত্র গ্রহণ করার সাথে সাথেই **১৪টি কাজের তালিকা** তৈরি হয়:

|---|---|

| **HR admin** | রেফারেন্স যাচাই, চুক্তিপত্র, পে-রোল, ব্যাংক তথ্য |
| **IT setup** | ইমেইল অ্যাকাউন্ট, ল্যাপটপ, অ্যাক্সেস কার্ড |
| **Introductions** | প্রথম সপ্তাহের সূচি, বাডি নিয়োগ, অফিস পরিচিতি |
| **Training** | ওরিয়েন্টেশন, নীতিমালা ব্রিফিং, প্রশিক্ষণ পরিকল্পনা |

- প্রতিটি কাজের **শেষ তারিখ** যোগদানের তারিখ থেকে হিসাব করে বসে যায়
- চেকবক্সে টিক দিলে কাজ শেষ হিসেবে গণ্য হয়
- দেরি হয়ে যাওয়া কাজ **লাল রঙে** দেখায়
- নিজের প্রয়োজনমতো নতুন কাজ যোগ করতে পারবেন

## ৬. AI চালু করা (খুব গুরুত্বপূর্ণ)

**এখন AI বন্ধ আছে।** তাই CV পড়া ও স্কোর দেওয়া হচ্ছে সাধারণ নিয়মভিত্তিক
পদ্ধতিতে — কাজ করে, কিন্তু AI-এর মতো ভালো না।

### চালু করার নিয়ম

1. **API key নিন:** https://console.anthropic.com → Settings → API Keys
2. `apps/api/.env` ফাইলটি খুলুন
3. এই লাইনটি খুঁজে বের করুন:
   ```
   ANTHROPIC_API_KEY=
   ```
4. সমান চিহ্নের পরে আপনার key বসান:
   ```
   ANTHROPIC_API_KEY=sk-ant-এখানে-আপনার-key
   ```
5. ফাইল সেভ করুন, **API টার্মিনালে `Ctrl+C` চেপে বন্ধ করে আবার `pnpm dev`** চালান

### চালু হয়েছে কিনা বুঝবেন কীভাবে

ব্রাউজারে যান: **http://localhost:4000/api/health**

দেখবেন `"ai":"configured"` — আগে ছিল `"ai":"disabled"`।

> 🔒 `.env` ফাইলটি GitHub-এ যায় না (`.gitignore`-এ আছে)। আপনার key নিরাপদ।

## ৭. সমস্যা ও সমাধান

| সমস্যা | কারণ | সমাধান |
|---|---|---|
| পেজ খুলছে না / সাদা স্ক্রিন | তিনটি টার্মিনালের কোনোটা বন্ধ | তিনটিই চালু আছে কি না দেখুন |

| লগইনে `429 Too Many Requests` | এক মিনিটে ১০ বারের বেশি চেষ্টা | ১ মিনিট অপেক্ষা করুন |
| লগইনে "Invalid email or password" | বানান ভুল | পাসওয়ার্ড: `Veyra12345` |
| ডেটা উধাও | seed আবার চালানো হয়েছে | `pnpm db:seed` আবার চালান |
| পেজ ফাঁকা দেখাচ্ছে | seed চালানো হয়নি | `cd apps/api && pnpm db:seed` |
| 404 This page could not be found | ভুল URL | বাম মেনুর লিংক ব্যবহার করুন |
| ইমেইল আসছে না | SMTP সেট নেই | API টার্মিনালে দেখুন, ইমেইল সেখানে লেখা হয় |
| পোর্ট দখল করা আছে | আগের প্রসেস চলছে | Task Manager থেকে `node.exe` বন্ধ করুন |

### সব ঠিক আছে কি না পরীক্ষা করুন

```bash
curl http://localhost:4000/api/health
```

`"status":"ok"` এলে সব ঠিক আছে।

## ১০. আসল ব্যবহারের আগে অবশ্যই করণীয়
